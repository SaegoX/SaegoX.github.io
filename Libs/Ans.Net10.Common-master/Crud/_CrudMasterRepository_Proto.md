# _CrudMasterRepository_Proto<T>

**Пространство имён:** `Ans.Net10.Common.Crud`  
**Исходный код:** `_CrudMasterRepository_Proto.cs`

---

## Назначение

Абстрактный базовый класс репозитория для работы со справочными (master) сущностями. Реализует общий функционал CRUD-репозитория и предоставляет дополнительные методы для создания новых объектов и получения количества записей.

## Основные возможности

- Наследует базовый CRUD-репозиторий
- Работает только с сущностями, реализующими интерфейс `IMasterEntity`
- Позволяет получить новый экземпляр сущности
- Позволяет получить количество записей в таблице
- Использует `Entity Framework Core` для доступа к данным

## Ограничения типа

Тип `T` должен:

- быть ссылочным типом (`class`)
- реализовывать интерфейс `IMasterEntity`

## Публичные методы

| Метод | Описание |
|-------|----------|
| `GetNew()` | Возвращает новый экземпляр сущности. Метод должен быть реализован в производном классе. |
| `GetItemsCount()` | Возвращает количество записей в соответствующей таблице базы данных. |

## Связанные интерфейсы

### IMasterEntity

Интерфейс, который должен реализовывать каждый справочник.

| Свойство | Описание |
|----------|----------|
| `Id` | Уникальный идентификатор сущности. |

### ICrudMasterRepository<T>

Расширяет интерфейс `ICrudRepository<T>` и определяет дополнительные методы для работы со справочниками.

| Метод | Описание |
|-------|----------|
| `GetNew()` | Создаёт новый экземпляр сущности. |
| `GetItemsCount()` | Возвращает количество элементов в репозитории. |

## Пример использования

```csharp
public class EmployeeRepository
    : _CrudMasterRepository_Proto<Employee>
{
    public EmployeeRepository(AppDbContext db)
        : base(db)
    {
    }

    public override Employee GetNew()
    {
        return new Employee();
    }
}

var repository = new EmployeeRepository(dbContext);

Employee employee = repository.GetNew();
int count = repository.GetItemsCount();
```

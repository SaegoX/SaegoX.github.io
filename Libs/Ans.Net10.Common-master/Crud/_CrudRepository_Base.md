## Назначение

Базовый класс репозитория, реализующий интерфейс [`ICrudRepository<T>`](common/crud/ICrudRepository.md). Предоставляет готовую реализацию CRUD-операций (Create, Read, Update, Delete) с использованием Entity Framework Core. Класс является фундаментом для построения более специализированных репозиториев (например, для справочников, связей «многие-ко-многим» и т.д.).

Класс **абстрактный** (хотя не содержит явного `abstract` в объявлении, слово `abstract` не используется — на самом деле это обычный класс с виртуальными методами, предназначенный для наследования; вы можете сделать его `abstract`, если хотите запретить прямое использование). Все методы объявлены как `virtual`, что позволяет переопределить их в наследниках при необходимости.

## Основные возможности

- Единая точка доступа к `DbContext` и `DbSet<T>`.
- Типизированные методы чтения: по идентификатору, с фильтром, получение количества.
- Полный набор операций изменения: добавление, обновление (полное и выборочное), удаление (по сущности или по id).
- Поддержка управления связями «многие-ко-многим» через методы `AddManyrefs`, `RemoveManyrefs`, `ManyrefUpdate` (базовая реализация генерирует `NotImplementedException` — их нужно переопределять при необходимости).
- Использование `AsNoTracking()` для запросов только на чтение, что повышает производительность.
- Автоматическое присоединение (`Attach`) сущностей при обновлении и удалении, если они не отслеживаются контекстом.

## Ограничения типа

Тип `T` должен быть **ссылочным типом** (`class`). Никаких других ограничений не накладывается — класс работает с любыми сущностями EF Core.
